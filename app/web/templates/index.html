CRITICAL

CICD-001: Hardcoded secret in workflow

Plaintext API keys, passwords, or cloud tokens detected in workflow YAML definition.

× Before 
# Vulnerable workflow snippet
env:
  API_KEY: "sk_live_abc123"
steps:
  - run: echo $API_KEY
✓ After (Recommended) 
# Remediated secure workflow
env:
  {% raw %}API_KEY: ${{ secrets.PROD_API_KEY }}{% endraw %}
steps:
  - run: echo $API_KEY
