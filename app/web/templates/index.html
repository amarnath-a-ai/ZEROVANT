How ZEROVANT Works

A deterministic, viva-defensible static security analysis data pipeline.

Step 01

Ingestion

GitHub API client with strict SSRF controls or direct YAML paste.

Step 02

YAML Parser

Constructs line-accurate Workflow object model hierarchy.

Step 03

Rule Engine

Evaluates 25 Core and 5 Extension rules yielding tagged findings.

Step 04

Correlation & Score

Correlates multi-rule attack chains and calculates risk scores.

Step 05

Remediation

Generates unified diff patches and stores history in SQLite.
